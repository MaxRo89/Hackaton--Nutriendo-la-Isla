# Contexto del proyecto

**Nombre:** Nutriendo la Isla.
**Lugar:** Ciudad del Carmen, Campeche.
**Categoría:** Hack for Humanity Challenge.
**Producto:** aplicación web responsiva (no app móvil nativa).

## Problema
Comercios con excedentes alimentarios aprovechables y personas con dificultades para acceder a alimentos carecen de un canal simple y coordinado para conectarse. La distribución requiere seguridad alimentaria, privacidad y logística.

## Solución
Los restaurantes publican donaciones disponibles; las personas beneficiarias registradas y aprobadas pueden consultar ofertas, solicitar una y coordinar la recogida. Un mapa ayuda a ubicar puntos de entrega. El equipo administrador revisa solicitudes de acceso y reportes.

## Principios
Dignidad, privacidad, acceso equitativo, trazabilidad, seguridad alimentaria, claridad sobre el uso de IA.

## Fuera del MVP
Pagos, entregas a domicilio, verificación automatizada de pobreza, diagnósticos de salud, aprobación sanitaria automática, integración oficial con gobierno.
